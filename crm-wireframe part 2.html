The user is Active (not in the FNF period)

What will happen:
• CM004 → status "Reversed", amounts set to ₹0
• CM005 (Adjustment) → new row with a ₹8,000 deduction, parent_commission_id = CM004
• Audit log entry with a special flag
• Weekly report reversal count incremented by 1
